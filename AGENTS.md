# AGENTS.md — Informasi (Landing Page Portal)

## Project Overview
Public landing page and information portal for TK Al-Mustam built with Vite, React 19, and TailwindCSS v4.

## Setup & Commands
- **Install**: `npm install`
- **Dev Server**: `npm run dev`
- **Build**: `npm run build` (`tsc -b && vite build`)
- **Lint**: `npm run lint` (`oxlint`)
- **Preview**: `npm run preview`

## Conventions
- Client-side routing with `react-router-dom` v7.
- Icons: `lucide-react`.
- Always run `npm run lint` and verify `npm run build` before finishing changes.
